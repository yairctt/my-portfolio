## Sobre este repositorio

Portafolio personal hecho con **React**, **Vite**, **Tailwind CSS** y **Preline**. Está disponible en español e inglés y tiene modo claro y oscuro.

### Ejecutar en local

```bash
npm install
npm run dev
```

### Editar el contenido

- Los textos, proyectos, experiencia y certificaciones están en `src/data/user_info_es.js` (español) y `src/data/user_info.js` (inglés).
- Las capturas de los proyectos van en `public/projects/` (formato `.webp`, 1200x750).
- El CV que se descarga desde el sitio es `public/cv/CV_Yair_Cruz_Torres.pdf`.
