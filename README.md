## Proyectos Destacados

### [Tutorías ISC](https://tutoriasisc.com)
Plataforma educativa de alto rendimiento bajo arquitectura **Serverless**.
- **Stack:** Node.js, Vercel Functions, Cloudflare R2, Upstash Redis.
- **IA:** Asistente integrado con RAG (Gemini API).
- **UI:** Interfaz Glassmorphism moderna y accesible.

### [Giang Aluminum](https://giangaluminum.com)
Sitio corporativo optimizado para SEO y conversión de leads.
- **Stack:** Vanilla JS, CSS3, Google Workspace API.

Compilador robusto para un lenguaje personalizado.
- **Stack:** Java, JavaCC.
- **Optimización:** Análisis de flujo de datos y eliminación de código muerto.
