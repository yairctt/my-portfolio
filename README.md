## Instalación
1. Clona el repositorio
    ```bash 
    git clone https://github.com/yairctt/my-portfolio.git
    ```
2. Entra al directorio
    ```bash
    cd my-portfolio
    ```
3. Instala las dependencias
    ```bash
    npm install 
    ```

## Uso
Para iniciar el servidor de desarrollo:
```bash
npm run dev
```
